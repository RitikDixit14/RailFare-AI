## 📌 Project Overview
**RailFare AI** is an advanced, data-driven web application designed to forecast and analyze dynamic surge pricing for Indian Railways. Built using a robust hybrid architecture, the platform combines a trained Machine Learning model (Random Forest Regressor) with an intelligent rule-based guardrail system to predict ticket prices based on capacity, time-to-journey, and travel class. 

This project demonstrates an end-to-end ML pipeline, from offline data warehousing to real-time inference via a highly interactive Streamlit dashboard.

## 🚀 Key Features
* **Hybrid AI Engine:** Utilizes offline-trained models alongside a dynamic simulation fallback to guarantee 100% uptime and accurate fare predictions.
* **Real-Time Analytics:** Interactive UI offering live journey metrics, surge probability tracking, and waitlist forecasting.
* **Advanced Visualizations:** Includes 7-Day Fare Forecast curves and Weekly Route Rush Heatmaps built with Plotly.
* **Offline Data Warehouse:** Implements a Master Database approach for lightning-fast querying, bypassing live API rate limits.
* **Compare & Export:** Users can save predicted routes to a cart and export comprehensive CSV reports.

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit, Custom CSS (Cyberpunk Theme)
* **Backend:** Python
* **Machine Learning:** Scikit-Learn, Pickle (Model Serialization)
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Plotly Express
* **APIs & Environment:** Requests, Python-dotenv
